# Nokia Snake '97 - Web Edition (HTML5 & JavaScript)

This is a responsive, standalone HTML5 and JavaScript recreation of the iconic Nokia mobile phone Snake game (Snake II / 3310).

## Features
- **Responsive for Mobile Browsers**: Optimized for mobile Safari (iPhone) and Chrome (Android), as well as desktop browsers.
- **Nokia 3310 Phone Casing Mode & Fullscreen Arcade Mode**: Switch between the nostalgic physical phone frame with clickable 3310 keypad, and full-screen arcade touch mode.
- **Touch & Gestures**: Swipe controls directly on the LCD screen, touch D-pad, and keypad buttons.
- **Nostalgic 8-bit Audio**: Monophonic square-wave beeps built with Web Audio API (no external sound files required).
- **5 Classic Nokia Mazes**: Open (wrap-around), Box (Border), Tunnel, Mill (Cross), and Rails.
- **9 Speed Levels**: From relaxed retro to super fast.
- **Bonus Beetles**: Timed creatures that appear every 5 foods.
- **Color Themes**: Nokia 3310 Green LCD, 3210 Amber / Orange, 1100 Ice Blue, and Monochrome Gray.
- **High Scores**: Stored in browser `localStorage`.

## Playing on iPhone / Android:
1. Open `index.html` in Safari (iPhone) or Chrome (Android).
2. On iPhone: Tap the **Share icon ⎋** -> **"Add to Home Screen"** to run full-screen without address bars like a native app.
3. On Android: Tap the menu (three dots) -> **"Install app"** or **"Add to Home screen"**.
